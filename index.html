🕸️
知識圖譜
用 Tree-sitter AST 解析程式碼，預先計算呼叫鏈、依賴與型別關係。
⚡
零伺服器架構
CLI 本地索引或純瀏覽器 WASM 執行，程式碼完全不離開你的機器。
🔌
MCP 整合
16 個 MCP 工具接入 Claude Code、Cursor、Codex，零 Token 消耗的索引。
💥
影響分析
Blast Radius 爆炸半徑分析，改動前先看清楚會牽動哪些檔案。
🔍
混合搜尋
BM25 + Semantic Embeddings + RRF 融合排名，理解語義而非字串比對。
⚖️
工具選型
與 Graphify、CodeGraph、Understand-Anything 橫向比較，選對工具。
