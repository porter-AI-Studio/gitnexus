第 1 章 · Part 1：認識 GitNexus

GitNexus 是什麼？零伺服器程式碼智慧引擎

把任何 codebase 變成 AI 能讀懂的知識圖譜——每一條依賴、每一段呼叫鏈、每一個執行流程，都預先計算好在等你問

一句話定位

GitNexus 的 GitHub README 開頭寫著一句話：

Building nervous system for agent context.

把任何程式碼庫索引成知識圖譜——每條依賴、每條呼叫鏈、每個集群、每個執行流程——再透過智慧工具暴露給 AI agent，讓它永遠不會漏掉程式碼。

更精準的類比是官方給的：Like DeepWiki, but deeper. DeepWiki 幫你理解程式碼，GitNexus 讓你分析它——因為知識圖譜追蹤的是每一條關係，而不只是文字描述。

簡單說：GitNexus 是一個在索引階段就把程式碼庫的結構關係預先計算好的引擎，讓 AI agent（Cursor、Claude Code、Codex 等）能在單次工具呼叫中拿到完整上下文，而不是靠十幾輪 grep 拼湊。

核心特性一覽

特性 說明
零伺服器（Zero-Server） CLI 模式完全本地執行；Web UI 模式純瀏覽器 WASM，程式碼不上傳任何外部伺服器
知識圖譜（Knowledge Graph） 用 Tree-sitter AST 解析程式碼，把函式、類別、模組的呼叫、依賴、繼承關係建成圖
預計算關係智慧 聚類、呼叫鏈追蹤、影響範圍——全在索引時算好，查詢時一次返回，不靠 LLM 運行時探索
MCP 整合 16 個 MCP 工具，接入 Claude Code、Cursor、Codex、Windsurf、OpenCode、Antigravity
Graph RAG Agent 內建 Graph RAG，可直接在 Web UI 與 codebase 對話
混合搜尋 BM25 + 語義向量 + RRF 融合排名，理解語義而非只做字串比對
隱私優先 所有資料留在本地 .gitnexus/，無網路傳輸
16 種語言 TypeScript/JS、Python、Java、Kotlin、C#、Go、Rust、PHP、Ruby、Swift、C/C++、Dart、Vue、Cobol

兩種使用模式

GitNexus 提供兩條入口，對應不同使用場景：

CLI + MCP Web UI
適合 日常開發，搭配 Cursor、Claude Code、Codex、Windsurf 使用 快速探索、Demo、一次性分析
規模 任意大小 repo，無限制 約 5,000 個檔案（受瀏覽器記憶體上限）
安裝 npm install -g gitnexus 免安裝，gitnexus.vercel.app
儲存 LadybugDB native（快速、持久化） LadybugDB WASM（記憶體內，session 後消失）
解析 Tree-sitter 原生綁定 Tree-sitter WASM
隱私 完全本地，無網路 完全在瀏覽器，無伺服器
💡
Bridge 模式：兩者兼得

執行 gitnexus serve 可以啟動本地 backend，Web UI 會自動偵測並連上，讓你在瀏覽器裡的視覺化介面存取 CLI 索引的完整大型 repo，突破 5,000 個檔案的瀏覽器記憶體限制。

30 秒快速上手

不需要任何前置配置，在 repo 根目錄執行兩行指令就能完成所有初始化：

快速上手 
# 從 repo 根目錄執行，一行完成索引
npx gitnexus analyze

# 設定 MCP（一次性，自動偵測你的編輯器）
npx gitnexus setup

npx gitnexus analyze 一行指令會完成：程式碼庫索引、Agent Skills 生成、Claude Code Hooks 註冊、AGENTS.md / CLAUDE.md 上下文檔案建立——全部一次搞定。

16 個 MCP 工具：AI Agent 的武器庫

GitNexus 透過 MCP（Model Context Protocol）暴露 16 個工具，讓 AI agent 可以直接查詢程式碼知識圖譜，不再靠 trial-and-error 的 grep：

工具 功能 典型使用場景
impact 爆炸半徑（Blast Radius）分析，含深度分組與置信度評分 修改函式前先看影響範圍
context 符號 360 度視角：所有呼叫者、被呼叫者、所屬執行流 理解一個函式在整個系統中的角色
query 混合搜尋（BM25 + 語義 + RRF），回傳排序後的相關符號 用自然語言找程式碼
detect_changes Git diff 影響映射：變更行 → 受影響的執行流程 提交前確認改動的實際影響
rename 圖層級安全重命名，回傳所有需要同步修改的位置 重構時的跨檔案符號更名
cypher 直接執行 Cypher 圖查詢 進階使用者自訂圖探索
list_repos 列出所有已索引的倉庫 多倉庫管理

完整 16 個工具（含多倉庫群組工具）的詳細說明見第 11 章。

支援的編輯器

編輯器 MCP Skills Hooks 自動增強 支援等級
Claude Code ✅ ✅ ✅ PreToolUse + PostToolUse 完整
